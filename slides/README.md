# Web slide deck

Open `index.html` directly, or serve this directory locally:

```bash
python3 -m http.server 8000 --directory slides
```

Then open <http://localhost:8000>.

Keyboard controls:

- Arrow keys, Page Up/Down, or Space: navigate
- `O`: slide overview
- `N`: speaker notes and source pointers
- `F`: fullscreen
- `?`: keyboard help

The deck is self-contained and has no network dependencies.
